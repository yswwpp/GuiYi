# GuiYi-产品需求文档

> 本地优先的个人知识收集与检索系统

---

## 一、产品概述

### 1.1 产品定位

GuiYi（归一）是一款 macOS 桌面应用，帮助用户将分散在各个平台的文档、网页、笔记统一管理，实现"一处搜索，全平台查找"。

### 1.2 解决的问题

| 痛点 | 说明 |
|-----|------|
| 信息分散 | 文档散落在飞书、本地文件、印象笔记等多个平台，查找困难 |
| 收藏即遗忘 | 看到好文章收藏后，再也没有打开过 |
| 搜索困难 | 只记得大概内容，关键词搜索找不到 |
| 隐私顾虑 | 不想把私人文档上传到云端服务 |
| 空间浪费 | 同一份文档在多个平台重复存储 |

### 1.3 核心价值

- **一键保存**：快捷键呼出，粘贴链接即保存
- **统一检索**：一次搜索，查找所有平台内容
- **智能理解**：用自然语言搜索，不需要精确关键词
- **本地优先**：数据在本地处理，保护隐私安全
- **来源跳转**：搜索结果可直接跳转回原平台

## 三、功能需求

### 3.1 核心功能

#### F1 快速保存

**功能描述**：用户可通过全局快捷键快速保存网页内容。

| 操作 | 说明 |
|-----|------|
| 唤醒 | 按 `Cmd + Shift + S` 呼出悬浮窗 |
| 粘贴 | 自动读取剪贴板中的链接 |
| 保存 | 点击保存按钮，文章自动存入本地 |
| 反馈 | 保存成功后显示提示 |

**保存内容**：
- 文章标题
- 正文内容
- 图片（下载到本地）
- 来源链接

#### F2 语义搜索

**功能描述**：用户可以用自然语言描述要找的内容，系统智能匹配相关文档。

**使用场景**：
- 用户输入："上周存的 Python 教程"
- 系统返回：所有与 Python 教程相关的文档

**搜索范围**：
- 已保存的网页
- 飞书文档
- 本地文件

**搜索结果**：
- 显示文档标题
- 显示内容摘要
- 显示来源平台
- 点击可跳转到原文

#### F3 飞书文档索引

**功能描述**：将飞书知识库和云盘文档建立索引，无需登录飞书即可搜索查找。

**支持内容**：
- 飞书文档
- 飞书 Wiki
- 云盘文件

**多账号支持**：
- 支持添加多个飞书账号（公司账号 + 个人账号）
- 搜索时可按账号筛选

**同步机制**：
- 首次添加账号时建立索引
- 之后可设置定时自动同步
- 只更新有变化的文档

#### F4 本地文件索引

**功能描述**：将本地电脑上的文档建立索引，实现快速搜索。

**支持格式**：
| 格式 | 说明 |
|-----|------|
| PDF | PDF 文档 |
| Word | .doc / .docx 文件 |
| Excel | .xls / .xlsx 文件 |
| PPT | .ppt / .pptx 文件 |
| Markdown | .md 文件 |
| 纯文本 | .txt 文件 |

**配置选项**：
- 添加要索引的文件夹
- 选择要索引的文件类型
- 设置排除的文件夹（如 .git、node_modules）
- 设置最大文件大小限制

**安全保证**：
- 只读取文件内容，不修改、不删除
- 敏感路径自动排除

#### F5 AI 智能摘要

**功能描述**：对于较大的文件，系统自动调用 AI 生成摘要和标签，提高搜索准确性。

**工作流程**：
1. 检测到较大文件（可配置阈值）
2. AI 分析文档内容
3. 生成摘要和标签
4. 将摘要和标签加入索引

**配置选项**：
- 设置触发 AI 摘要的文件大小阈值
- 配置 AI 服务地址（支持 OpenAI 兼容的 API）
- 配置使用的模型

### 3.2 设置管理

#### S1 通用设置

| 设置项 | 说明 |
|-------|------|
| 开机启动 | 系统启动时自动运行 |
| Dock 图标 | 是否在 Dock 中显示图标 |

#### S2 同步设置

| 设置项 | 说明 |
|-------|------|
| 数据源管理 | 查看、添加、删除数据源 |
| 同步频率 | 设置自动同步的时间间隔 |
| 手动同步 | 立即触发同步 |

#### S3 AI 设置

| 设置项 | 说明 |
|-------|------|
| 启用 AI | 是否启用 AI 摘要功能 |
| API 地址 | AI 服务的接口地址 |
| API 密钥 | 访问 AI 服务的密钥 |
| 模型选择 | 使用的 AI 模型名称 |
| 触发阈值 | 多大的文件触发 AI 摘要 |

#### S4 存储设置

| 设置项 | 说明 |
|-------|------|
| 存储位置 | 设置本地文档存储目录 |
| 查看存储 | 查看已存储的文档 |

## 四、非功能需求

### 4.1 性能要求

| 指标 | 要求 |
|-----|------|
| 启动时间 | 应用启动时间 < 3 秒 |
| 搜索响应 | 搜索响应时间 < 2 秒 |
| 同步效率 | 1000 个文档增量同步 < 1 分钟 |

### 4.2 安全要求

| 要求 | 说明 |
|-----|------|
| 数据本地化 | 所有数据在本地处理，不上传云端 |
| 凭证安全 | 敏感凭证（API Key、Token）存储在 macOS 钥匙串 |
| 只读操作 | 本地文件只读取内容，不修改、不删除 |

### 4.3 兼容性要求

| 要求 | 说明 |
|-----|------|
| 操作系统 | macOS 12.0 及以上 |
| 芯片架构 | 支持 Intel 和 Apple Silicon |

## 六、使用流程

### 6.1 首次使用

1. 安装应用
2. 授予辅助功能权限（用于快捷键）
3. 配置存储位置
4. 添加数据源（飞书账号、本地文件夹）
5. 触发首次同步

### 6.2 日常使用

**保存网页**：
1. 浏览器中复制文章链接
2. 按 `Cmd + Shift + S` 唤出悬浮窗
3. 链接自动填入
4. 点击保存

**搜索文档**：
1. 打开应用界面
2. 输入搜索词或自然语言描述
3. 查看搜索结果
4. 点击跳转到原文
