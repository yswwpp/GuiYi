# 新增需求 1 - 实现记录

## 需求内容

### 1. 搜索结果显示数据源图标

在搜索结果列表中，每个条目前显示数据源的 logo：
- 飞书：蓝色纸飞机图标
- 本地文件：橙色文件夹图标
- 网页：绿色地球图标
- 印象笔记：绿色笔记图标
- 夸克网盘：蓝色云图标

### 2. 元数据存储从 SQLite 迁移到 MySQL

将程序运行相关的元数据从 SQLite 迁移到 MySQL 数据库：
- 地址：127.0.0.1
- 端口：6612
- 用户：guiyi_user
- 数据库：guiyi

数据库连接配置写入配置文件。

## 实现方案

### 1. 搜索结果图标

**文件变更**：
- `guiyi-client/GuiYi/SearchView.swift`

**实现方式**：
- 使用 SwiftUI 的 `@ViewBuilder` 创建 `sourceIcon` 函数
- 根据 `source` 字段返回不同的图标视图
- 图标使用圆形背景 + SF Symbols 组合
- 不同数据源使用不同颜色区分

**图标设计**：
| 数据源 | SF Symbol | 背景色 |
|-------|-----------|-------|
| feishu | paperplane.fill | 蓝色 |
| local | folder.fill | 橙色 |
| web | globe | 绿色 |
| yinxiang | note.text | 绿色 |
| quark | cloud.fill | 蓝色 |

### 2. MySQL 迁移

**新增文件**：
- `guiyi-server/data/db_config.json` - 数据库配置文件

**文件变更**：
- `guiyi-server/sync/metadata.py` - 重写支持 MySQL

**实现方式**：
1. 创建 `DatabaseConfig` 类加载配置文件
2. 支持 MySQL 和 SQLite 双数据库（向后兼容）
3. 使用 pymysql 连接 MySQL
4. 自动创建数据库和表结构
5. 迁移现有 SQLite 数据到 MySQL

**配置文件格式**：
```json
{
    "database": {
        "type": "mysql",
        "host": "127.0.0.1",
        "port": 6612,
        "user": "guiyi_user",
        "password": "your_password",
        "database": "guiyi"
    }
}
```

**MySQL 表结构**：

```sql
CREATE TABLE sync_metadata (
    id VARCHAR(255) PRIMARY KEY,
    source VARCHAR(50) NOT NULL,
    account VARCHAR(255),
    url TEXT,
    title TEXT,
    content_hash VARCHAR(64),
    file_size BIGINT DEFAULT 0,
    file_mtime DOUBLE DEFAULT 0,
    ai_summary TEXT,
    ai_tags TEXT,
    last_modified DOUBLE,
    last_synced DOUBLE,
    sync_status VARCHAR(20) DEFAULT 'synced',
    created_at DOUBLE DEFAULT 0,
    INDEX idx_source_account (source, account)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE sync_logs (
    id INT AUTO_INCREMENT PRIMARY KEY,
    sync_time DOUBLE,
    source VARCHAR(50),
    account VARCHAR(255),
    action VARCHAR(50),
    doc_id VARCHAR(255),
    doc_title TEXT,
    error_message TEXT,
    INDEX idx_sync_time (sync_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
